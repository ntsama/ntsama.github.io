# Laboratoire d'Écriture IA  
## Pédagogie Texte-Image en Zones d'Éducation Prioritaires

Le **Laboratoire d'Écriture IA** est une innovation pédagogique développée au sein de l'initiative IA_4_ZEP. Elle utilise l'IA générative comme **outil de motivation et de feedback** pour l'écriture descriptive dans les grandes classes à faibles ressources (60+ apprenants).

---

### 1. Le problème pédagogique

Enseigner la description en ZEP se heurte à trois obstacles :
- Les classes surchargées rendent le feedback individuel impossible.
- Les apprenants peinent à comprendre ce qui rend une description « précise ».
- Les exercices d'écriture abstraits semblent déconnectés du vécu.

### 2. L'innovation : Écrire pour Voir

La méthode est simple : **si l'IA peut générer l'image, la description était claire. Sinon, elle doit être révisée.**

**Le déroulé :**
1. **Corpus :** Les apprenants étudient un personnage littéraire (ex : Faydé de *Cœur du Sahel*, œuvre au programme camerounais).
2. **Lecture :** Ils identifient les traits physiques, vêtements, posture, expressions, contexte.
3. **Écriture :** Chaque apprenant produit un court texte descriptif.
4. **Génération :** L'enseignant injecte chaque texte dans un générateur d'images IA.
5. **Confrontation :** L'image générée est comparée à l'intention de l'apprenant.
6. **Révision :** Les apprenants affinent leur description en fonction de ce que l'IA a mal compris.

### 4. Pourquoi cela fonctionne : fondements cognitifs

Cette méthode opérationnalise trois concepts du **Modèle du Trapèze Cognitif** :

- **Boucle courte (Apprenant–IA–Savoir) :** L'IA génère une réponse visuelle au texte de l'apprenant — feedback immédiat et tangible.
- **Savoir incarné :** La description abstraite devient une expérience concrète, visuelle et affective.
- **Pédagogie curative :** Les apprenants en difficulté sont soutenus par le résultat visuel, qui rend leurs progrès visibles.

---

### 5. Scalabilité & Accès ouvert

Cette méthodologie est :
- **Réplicable** à tous les niveaux et toutes les œuvres.
- **Adaptable** aux contextes bilingues (français / anglais).
- **Économique** — elle ne nécessite qu'un smartphone ou une tablette.

Toute la méthodologie, les fiches pédagogiques et les productions anonymisées des apprenants seront publiées sur **Zenodo** sous licence **CC-BY**.
